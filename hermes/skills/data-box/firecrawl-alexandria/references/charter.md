# Firecrawl Alexandria: charter

**Tier 1.** This is the first choice for business lists and for structured public records. It is billed in Firecrawl credits, from the same balance as the rest of Firecrawl.

## What it may do

- Discover and inspect tools at any time. Both are free (`sources: ["alexandria"]`, and `find-tools`).
- Run a tool, as a lane in an approved data-box plan only, within the plan's credit cap and page and query caps.
- Spend at most 25 credits of preflight before approval. The plan reports that as money already spent.

## What it may not do

- Accept third-party data terms. Only Justin, as an org admin, does that at the URL the error gives.
- Plan **Apollo** or **FullEnrich** lanes. They are excluded by policy (Justin, 2026-09-30), and people's contacts come from MoltSets, GetLeads or Consulti on the shortlist.
- Run a catalog tool that is not about the request. Only a general directory for the entity, or a tool whose description mentions the request's topic, qualifies. A source the user named is the exception.
- Swap in a different tool when the ranked one fails. The Hermes script did this, and data-box does not copy it.
- Treat an empty result as a success.

## Contact data

Records stay in the job's folder on the box and are deleted after the retention period (30 days proposed). Logs carry counts, never names, phones or emails.
